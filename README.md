# kitsun-obs-overlay

Nuxt 3 + Nitro + TypeScript MVP for a cross-platform chat overlay aggregator.

## Setup

```bash
pnpm install
pnpm dev
```

- Overlay: http://127.0.0.1:3000/overlay
- Dashboard: http://127.0.0.1:3000/dashboard

## Environment

Copy `.env.example` to `.env` and adjust as needed.
